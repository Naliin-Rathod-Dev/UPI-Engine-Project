# UPI-Engine-Project
UPI Engine Project is a small project build to understand the systems of digital wallet. 

Beginners can see this code and get an idea of how OOPs how to write and how it works. 
We will be coming up with storing the users in database instead of just using dictionaries and lists (Which are just temporarily stored in the RAM). 

What this system can really do for now is listed below:

1. Create a user (Username, PIN, Bank name, mobile number, and other basic details).
2. Make Payment to other users using Methods.
3. Get user's transaction list.

Note: There is just one app included for now i.e. PhonePe

This code is written in structured, industry based and scalable for production purposes so anyone reading our code will understand it clearly and use the formation in the code correctly.

Additional info: No application is being promoted here.
